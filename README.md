# Solara Bay: Vice Underground (GTA 6 Open-World Action)

An original 3D open-world action-adventure game set in the sun-drenched coastal metropolis of **Solara Bay**. Built with procedural 3D graphics in Three.js and dynamic WebAudio sound synthesis, playable entirely offline in any modern desktop browser.

## Story & Setting
Take control of **Maya Cruz**, an ambitious driver and street mechanic navigating the high-stakes criminal underworld of Solara Bay. Teaming up with veteran chop-shop kingpin **Eddie Ramos**, Maya takes on high-value vehicle repos, illicit contraband runs, and daring bank heists while battling the notorious rival syndicate **The Vultures** and evading relentless police pursuits.

## Features
- **Exploration On Foot & By Car**: Smooth arcade vehicle handling (steer, drift, handbrake, collisions) and on-foot mobility (sprint, jump, melee combat, firearm).
- **Dynamic Living City**: Procedurally generated neon-lit coastal city with sandy beaches, swaying palms, high-rise towers, road networks, traffic cars, and reactive pedestrians.
- **Wanted Level & Police Response**: 5-star wanted system triggering aggressive police cruisers, siren audio, spike maneuvers, and arrest/busted states.
- **Narrative Missions**: Multi-stage story objectives ("Repo Run", "Hot Package", "Bay Heist") with 3D beacons, dialogue popups, and cash rewards.
- **Interactive HUD & Live Minimap**: Real-time canvas radar showing roads, player heading, traffic, cops, and mission objectives.
- **Procedural WebAudio Synthesis**: Zero external audio files — procedural V8 engine pitch modulation, sirens, gunshots, tire screech, and retro synthwave soundtrack.

## How to Run Locally
1. Start the local development server:
   ```bash
   node serve.ts
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:8080
   ```
3. Controls:
   - **WASD / Arrow Keys**: Walk or Drive
   - **F / Enter**: Enter or Exit / Hijack Car
   - **Spacebar**: Jump (on foot) or Handbrake / Drift (in vehicle)
   - **Left Click**: Melee Punch / Shoot Handgun
   - **Right Click / Shift**: Aim Handgun / Sprint
   - **M**: Mute Audio
   - **Esc / P**: Pause Game
